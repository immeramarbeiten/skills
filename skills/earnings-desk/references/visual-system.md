# Editorial infographic art direction

## Principle
Make the information legible as financial journalism. Corporate character comes from a restrained accent color and authentic typographic cues, not an invented logo. Think intelligent newspaper infographics, *not a copy of FT/WSJ/Economist trade dress*. Numerical information should be rendered with vector text, not synthetic image-model text.

## Layout: 1600 x 1000 SVG (16:10)
- Upper 175px: company/ticker, quarter/date, thesis. Dark navy/charcoal masthead with brand accent rule.
- Left 930px: three hero KPI tiles, modest series chart, subtle reference grid.
- Right 490px: two report-card grades with five-star row, two condensed call findings, market tape result with session/time.
- Lower 100px: evidence/source footer, as-of line, `Illustrative demo — not live data` watermark when using example assets.

## Typography and hierarchy
Use system sans / Arial / Helvetica, large 52–64px headline, 34–44px KPI, 18–22px commentary, 13–16px captions, strong contrast. No more than 5–7 short text bullets. Keep adequate whitespace.

## Color
User/company IR color if verified; fallback `#192742` deep navy, `#4877DA` accent, `#F7F8FA` background, `#2D3548` body. Pos/neg surprise is a directional benchmark; don't use green/red as automatic evaluation. Charts must encode data with shapes and labeled values, not color alone. Avoid illegible brand yellows on white.

## Output and source rules
Use the supplied numbers and grades. Label units on each chart. Distinguish estimated (dashed, thin) vs reported (solid) lines. Display market move as one timestamp-specific fact, never a live ticker. Put source names, a report creation timestamp, and an example-data warning when applicable.

## Distribution
One landscape SVG for web and PDF, PNG for social, optionally a separate 1080x1350 portrait version for Instagram as a later enhancement. Don't force an illegibly dense 280-character tweet into the graphic. Keep the core report text separately for accessibility.
